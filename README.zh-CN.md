# Work Tracker

[English](README.md) | 简体中文

用于个人工作记录、共享任务、Engineering 与 QA 流程和版本发布计划的网页应用。

## 主要功能

- Dashboard 摘要、下一步待办及按日期记录的活动。
- 私人项目、重复任务、工作备注和附件。
- Engineering、PM 和 Quick Task，共享筛选、卡片及列表视图。
- PM 交接、PR 审核、QA 轮次、反馈关联回复及生产交付。
- 发布计划与历史快照；此功能不是 Git 仓库管理。
- 工作量视图、任务编号、紧急信号与提醒。
- 账号管理、明确的工作组资格、只读管理视图及审计历史。
- 默认英文，可按账号启用中文系统说明。

## 本地预览

使用 Node.js 22.13 或以上版本，并确保内置 `node:sqlite` 可用。

```sh
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。预览会生成独立的 SQLite 数据库和 `.local-files/`，使用示例账号及开发认证，仅供本地评估。

## 验证

```sh
npm test
node scripts/build.mjs
```

构建会在 `dist/` 生成 Worker 和数据库迁移文件。自动化测试不能替代浏览器与托管环境集成验证。

## 目录结构

- `public/`：HTML、CSS、JavaScript 与图片资源。
- `server.mjs`：HTTP API、权限及业务规则。
- `task-signals.mjs`：任务信号计算。
- `node-server.mjs`：本地预览与存储适配。
- `schema.sql`、`migrations/`：基础结构与增量迁移。
- `scripts/`：构建工具。
- `tests/`：自动化测试。
- `maintenance/`：数据库检查点与恢复说明。

## 部署与数据

托管实现使用 Cloudflare Workers、D1（`DB`）及 R2（`BUCKET`）。独立安装时需要自行配置资源、前端文件、账号初始化及运行参数。包内保留存储绑定声明，不含现有项目身份。

此包不是任意平台的一键部署版本。其他服务器环境需要适配存储接口和正式服务器入口。首次管理员设置依赖可信上游身份请求头，不能直接信任客户端提交的身份头。本地预览不能作为生产服务器开放。

保留已经执行的迁移，通过新增迁移变更结构。凭据、环境变量文件、SQLite 数据库及其附属文件、上传文件不应提交到版本控制。基础设施检查点可能包含私人和认证数据，必须保留在数据库访问权限边界内。

私人 Daily Work 仅允许本人及获授权的只读管理角色查看。共享任务按工作组与负责人规则控制，管理员权限不会自动赋予 Engineering 或 QA 负责人资格。
