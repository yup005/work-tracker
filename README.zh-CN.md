# Work Tracker

[English](README.md) | 简体中文

Work Tracker 是一个用于个人工作记录、团队任务协作、Engineering 与 QA 流程以及版本发布计划的网页应用。

## 主要功能

- **Dashboard**：每日活动摘要和下一步待办。
- **Daily Work**：私人项目、任务、重复任务、工作记录及附件。
- **共享任务看板**：支持 Engineering、PM 和 Quick Task，提供搜索、筛选、分类、卡片与列表视图。
- **PM 交接**：需求、设计参考和交接历史保留在同一任务中，交接后继续进入 Engineering 流程。
- **Engineering 与 QA**：阶段推进、可行性审核、预计日期、QA 轮次、反馈及生产交付记录。
- **版本发布计划**：当前和未来计划、任务选择及历史发布快照。此功能记录应用发布计划，不是 Git 仓库管理工具。
- **工作量视图**：按日期查看工作活动、参与情况及 QA 退回记录。
- **权限管理**：账号管理与明确的工作组成员资格；管理员权限与 Engineering／QA 负责人资格分别控制。
- **历史记录**：活动修订、审计更正、归档与恢复，以及受限制的流程撤销。
- **语言支持**：默认英文，可按账号启用中文系统说明；用户输入的内容保持原样。

## 技术架构

| 部分 | 技术 |
| --- | --- |
| 前端 | HTML、CSS、JavaScript |
| 后端 | JavaScript HTTP API，使用标准 Request／Response |
| 托管运行环境 | Cloudflare Workers |
| 托管数据库 | Cloudflare D1，使用 `DB` 绑定 |
| 托管文件存储 | Cloudflare R2，使用 `BUCKET` 绑定 |
| 本地预览 | Node.js、SQLite、本地文件存储 |
| 自动化测试 | Node.js 内置测试运行器 |

## 环境要求

使用 Node.js 22.13 或以上版本，并确保内置 `node:sqlite` 可用。当前项目未声明第三方运行时依赖。

## 本地预览

在应用根目录运行：

```sh
npm run dev
```

在浏览器打开 `http://127.0.0.1:4173`。

如需更换端口：

```sh
PORT=4174 npm run dev
```

本地预览会建立独立的 SQLite 数据库和文件存储目录，并使用示例账号及开发认证模式。它用于本地评估，不能直接作为生产服务器。预览数据与托管应用的数据相互独立。

## 目录结构

```text
public/                 前端资源
server.mjs              应用 API 和业务规则
node-server.mjs         本地预览服务器与存储适配
schema.sql              基础数据库结构
migrations/             增量数据库迁移
scripts/build.mjs       Worker 构建与迁移打包
tests/                  自动化测试
package.json            运行要求与命令
```

## 测试

```sh
npm test
```

测试覆盖任务流程、权限、账号会话、附件及语言行为。自动化测试通过不能替代托管环境集成检查和浏览器验证。

## 部署说明

托管实现需要 Worker 运行环境、D1 数据库和 R2 存储桶。部署前需要配置这些资源、应用数据库迁移、提供前端资源，并设置账号初始化及运行配置。

当前本地预览不是正式部署适配器。部署到其他服务器平台时，需要适配数据库与文件存储接口，并提供正式服务器入口。首次管理员设置也需要检查：现有实现依赖可信上游身份请求头，不能直接信任客户端自行提交的身份请求头。

此源码包的构建配置保留数据库和存储绑定声明，不含现有托管项目身份。它不是可直接发布到任意平台的一键部署包。

升级已有安装时应保留迁移历史，通过新增迁移修改结构，不应重写已经执行的迁移。

## 数据与配置

不要将凭据、环境变量文件、数据库和上传文件提交到版本控制。本地预览会生成：

- `work-tracker-local.sqlite`
- `.local-files/`

源码分发时也应排除 SQLite 的 journal、WAL 和共享内存文件。管理员及可选集成配置应按安装环境分别设置，不应提交真实账号信息或访问令牌。

私人 Daily Work 仅允许本人及获授权的只读管理角色查看；共享任务按工作组与负责人规则控制。替换认证或存储接口时应保留这些权限边界。
